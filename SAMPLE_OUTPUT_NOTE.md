# About `etf_nav_dashboard_sample.png`

This environment doesn't have live internet access to Yahoo Finance, so this
image was generated by feeding `nav_engine.py` / `visualiser.py` a
representative 30-day synthetic yield curve and a plausible AGG price path
instead of a real `yfinance` pull — same code, same math, mocked inputs.
It's here so the repo has a preview image without requiring a live run.

To generate the real dashboard from live market data, just run, with
internet access:

```bash
pip install -r requirements.txt
python visualiser.py
```

That overwrites `etf_nav_dashboard.png` with real, current AGG/Treasury
data. Delete this note and the sample PNG once you've generated the real
one, or keep both — up to you.
